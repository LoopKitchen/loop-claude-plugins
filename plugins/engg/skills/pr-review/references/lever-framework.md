# LEVER Framework

## Optimization Principles

Think harder about each principle:
- **L**everage: Are they reusing existing patterns or creating new ones unnecessarily?
- **E**xtend: Did they extend existing code or duplicate functionality?
- **V**erify: Is the solution reactive/dynamic or hardcoded?
- **E**liminate: Look for code duplication across files
- **R**educe: Can this be simplified? Is there unnecessary complexity?

## Focus Areas

- Code duplication (same logic in multiple places)
- Complex functions that could be simplified
- Hardcoded values that should be dynamic
- New code that duplicates existing functionality
- Overly complex solutions to simple problems
- Test files that duplicate implementation logic
